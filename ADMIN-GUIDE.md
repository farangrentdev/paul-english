# Как управлять сайтом Paul English

Всё содержимое сайта редактируется через админку — без программиста.

**Адрес:** https://paul-english.ru/admin
**Логин:** `admin@pavelenglish.ru`

---

## Что где редактируется

### Контент сайта

| Раздел админки | Что меняет на сайте |
|---|---|
| **Настройки сайта** | Логотип, имя, слоган на главной, регалии, фото, бейдж на фото, блок «Обо мне», контакты, соцсети, строка в подвале |
| **Педагоги** | Блок «Наши педагоги»: имя, роль, теги, описание, фото |

| **Акции** | Плашки со скидками. Сейчас **скрыты на сайте** по вашей просьбе — данные сохранены, вернуть можно в любой момент |
| **Преимущества** | Блок «Что ты получишь, кроме грамматики» |
| **Виды занятий** | Блок «Найди свой формат» |
| **Отзывы** | Отзывы учеников (можно скрывать галочкой «Опубликован») |
| **FAQ** | Частые вопросы |
| **Материалы** | Страница «Бери и пользуйся» — бесплатные материалы |
| **Правовые документы** | Политика конфиденциальности, согласие, реквизиты |

### Работа со школой

| Раздел | Для чего |
|---|---|
| **Сводка** | Сколько новых заявок, учеников, оплат |
| **Заявки** | Все, кто записался на пробное. Меняйте статус: новая → связались → записан → завершено |
| **Ученики** | Карточка ученика: расписание, журнал с оценками, личные материалы, история оплат. Здесь же создаётся доступ в личный кабинет |

## Частые задачи

### Поменять текст на главной
**Настройки сайта** → нужное поле → «Сохранить». Изменения видны сразу.

### Загрузить логотип
**Настройки сайта** → поле «Логотип» → выбрать файл (PNG или SVG с прозрачным фоном) → «Сохранить».
Если логотип не загружен, показывается текстовый «Paul · English».

### Изменить бейдж на фото
**Настройки сайта** → «Бейдж на фото». Каждая строка = новая строка в жёлтом круге.
Оставьте поле пустым — бейдж исчезнет.

### Добавить отзыв
**Отзывы** → «+ Добавить отзыв» → заполнить → «Сохранить».
Порядок отображения задаётся полем «Порядок» (меньше = выше).

### Настроить расписание

Расписание ведётся **отдельно по каждому преподавателю** и работает в два шага.

**Шаг 1. Стандартное расписание (один раз).**
**Расписание** → выбрать преподавателя → вкладка **«Стандартное расписание»**.
Это шаблон обычной недели: в какие дни и часы человек в принципе работает.
- Клик по ячейке включает/выключает окошко.
- «+ Добавить в будни» — новое время сразу в Пн–Пт.

**Шаг 2. Открыть период (регулярно).**
Вкладка **«Календарь»** → кнопка **«Открыть период»**, выбрать на сколько недель вперёд.
Слоты создадутся по стандартному расписанию, и ученики смогут записываться.
- Клик по слоту снимает его с записи (например, вы заняты) или возвращает обратно.
- Ссылки «снять / вернуть» под колонкой закрывают или открывают весь день целиком.
- Повторное открытие периода безопасно: существующие слоты и записи не пострадают.

Ниже — **«Записи»**: кто и когда записался, включая имя ребёнка, если записали его.
Кнопка «Снять» освобождает слот и удаляет занятие.

> Чтобы преподаватель появился в расписании, откройте **Педагоги** → его карточка →
> галочка **«Участвует в онлайн-записи»**.

### Учёт занятий из пакета
В карточке ученика (**Ученики** → открыть) есть раздел **«Пакеты занятий»**: сколько
куплено и сколько осталось.

Занятие списывается, когда в разделе **«Расписание»** карточки вы ставите статус
**«проведено»**. Вернули статус в «план» — занятие возвращается на баланс.
Отменённые занятия не списываются.

Пакет начисляется автоматически после оплаты. Начислить вручную (например, при оплате
переводом) можно там же кнопкой **«+ Начислить пакет»**.

Чтобы автоначисление работало, у пакета в разделе **Пакеты** должно быть заполнено
поле **«Занятий в пакете»**.

### Если у родителя занимается несколько детей
В карточке ученика есть раздел **«Кто занимается»**. Аккаунт и оплата общие, а список
нужен, чтобы вы видели, с кем именно урок.

Добавьте ребёнка кнопкой **«+ Добавить человека»** (имя, кем приходится, заметка —
возраст, уровень). После этого при записи на сайте родитель выбирает, для кого занятие,
и вы видите это имя в разделе «Записи» и в расписании.

### Завести ученика с доступом в кабинет
**Ученики** → «+ Добавить ученика» → email, пароль, имя, пакет.
Дальше в карточке ученика добавляются занятия, оценки в журнал и личные материалы — всё это ученик видит у себя в кабинете.

## Личный кабинет ученика

Ученики заходят на https://paul-english.ru/cabinet своим email и паролем.
Там они видят: ближайшее занятие, расписание, журнал с оценками и комментариями, свои материалы и оплаты.

## Оплата

Приём платежей идёт через **ЮKassa**. Чтобы включить настоящие платежи, нужны `shopId` и секретный ключ из личного кабинета ЮKassa — их прописывает разработчик один раз.

Пока ключи не добавлены, кнопка оплаты работает в демо-режиме (оплата отмечается прошедшей, деньги не списываются) — удобно для тестирования.
